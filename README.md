# Deep-Learning
Deep Learning projects using CNNs, Transfer Learning and RNNs for image classification and medical diagnosis

# Deep Learning Projects

This is where things got interesting. Moving from traditional ML to deep learning 
meant thinking differently — less feature engineering, more architecture decisions.

These projects cover image classification, medical diagnosis, and transfer learning 
using real datasets.

## Projects

| Project | Architecture | Dataset | Accuracy |
|---------|-------------|---------|----------|
| CNN Image Classification | Custom CNN | CIFAR-10 | 76% |
| Pneumonia Detection | CNN | Chest X-Ray | - |
| Fashion MNIST | CNN | Fashion MNIST | - |
| Transfer Learning | VGG16/ResNet | Custom | - |

## What I learned

Building CNNs from scratch teaches you things no tutorial does — why certain 
architectures work, where models fail, and how data augmentation actually helps.

Pneumonia detection was the most meaningful one — applying deep learning to 
real medical imaging made the whole thing click differently.
